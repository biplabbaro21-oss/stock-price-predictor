# 📈 Stock Price Predictor

## 🔹 Project Overview
This project predicts stock prices based on historical data using **Linear Regression**.  
It fetches stock data from Yahoo Finance (`yfinance` library) and trains a regression model to estimate closing prices.  
The results are visualized with actual vs predicted price graphs.

---

## 🛠️ Technologies Used
- Python 3
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- yfinance

---

## ⚙️ How It Works
1. Download historical stock data (Apple Inc. used as example).
2. Convert dates into numeric values for regression.
3. Train a **Linear Regression model** on closing prices.
4. Predict prices and plot them against actual values.
